# German word-card lexicon

Generated by `scripts/build-lexicon.mjs` for #68. Do not edit the JSON by hand.

- **Source data:** English Wiktionary, extracted by [Wiktextract](https://github.com/tatuylonen/wiktextract) and published at [kaikki.org](https://kaikki.org/dictionary/German/) (dump of 30 October 2026).
- **Word selection:** the 50,000 most frequent words in [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (OpenSubtitles 2018, German). Lemmas found in Wiktionary are kept, up to 20,000; the current build has 19,822, plus 8,097 noun plurals that point to their singular entry ("personen" finds "Person") when the plural is not a word of its own.
- **License:** the data in `de/` is derived from Wiktionary and FrequencyWords and is licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The build script itself is project code.

## Format

`de/<letter>.json` maps a lowercase key (NFC, without a leading article) to entries:

```json
{ "band": [{ "w": "Band", "c": "noun", "g": ["n"], "pl": "Bänder", "gen": "Bandes" }] }
```

- `c`: word class (`noun`, `verb`, `adj`, `adv`, `intj`, `conj`, `prep`, `pron`, `det`, `article`, `num`, `particle`, `contraction`)
- `g`: genders, `m`/`f`/`n`, or `p` for plural-only nouns
- `pl`: standard nominative plural; `gen`: genitive singular (kept for #28)

## Rebuild

```sh
node --experimental-strip-types scripts/build-lexicon.mjs kaikki.org-dictionary-German.jsonl.gz de_50k.txt 20000
```
