# German lexicon

Generated by `scripts/build-lexicon.mjs` for the word card (#68) and the Explore view (#28). Do not edit the JSON by hand.

- **Source data:** English Wiktionary, extracted by [Wiktextract](https://github.com/tatuylonen/wiktextract) and published at [kaikki.org](https://kaikki.org/dictionary/German/) (dump of 30 October 2026).
- **Word selection:** the 50,000 most frequent words in [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (OpenSubtitles 2018, German). Lemmas found in Wiktionary are kept, up to 20,000; the current build has 19,822, plus 8,097 noun plurals that point to their singular entry ("personen" finds "Person") when the plural is not a word of its own.
- **License:** the data in `de/`, `de-details/` and `de-forms/` is derived from Wiktionary and FrequencyWords and is licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The build script itself is project code.

## Format

`de/<letter>.json` maps a lowercase key (NFC, without a leading article) to entries:

```json
{ "band": [{ "w": "Band", "c": "noun", "g": ["n"], "pl": "Bänder", "gen": "Bandes" }] }
```

- `c`: word class (`noun`, `verb`, `adj`, `adv`, `intj`, `conj`, `prep`, `pron`, `det`, `article`, `num`, `particle`, `contraction`)
- `g`: genders, `m`/`f`/`n`, or `p` for plural-only nouns
- `pl`: standard nominative plural; `gen`: genitive singular (kept for #28)

### Explore details

`de-details/<bucket>.json` uses the same keys, bucketed by the first two letters with umlauts folded (`gi.json` holds "ging…"), so one chunk is about 30 KB on average and 390 KB at most. Each entry repeats the card fields and adds:

```json
{ "w": "gehen", "c": "verb", "s": [{ "d": "to go, to walk", "ex": ["Ich gehe jetzt.", "I’m leaving now."] }], "ipa": "/ˈɡeːən/",
  "audio": "5/5f/De-gehen2.ogg", "conj": { "pres": ["gehe", "…"], "pret": ["ging", "…"], "pp": "gegangen", "aux": "sein", "imp": ["geh / gehe", "geht"] } }
```

- `s`: up to 5 English glosses, each with at most one example of 140 characters or fewer (German text, English translation)
- `ipa`: first IPA transcription; `audio`: Wikimedia Commons path, played as the transcoded MP3 (Commons files keep their own free licenses)
- `conj` (verbs): present and preterite indicative for ich, du, er/sie/es, wir, ihr, sie/Sie; past participle; auxiliary; imperative
- `decl` (nouns): nominative, genitive, dative, accusative, singular (`sg`) and plural (`pl`); `cmp` (adjectives): comparative, superlative
- Cells with several standard forms are joined with " / "; missing cells are `null`

`de-forms/<letter>.json` maps single-word inflected forms that are not words of their own to lemma keys (`"ging": ["gehen"]`). Separable forms written with a space ("fängt an") are not indexed.

### Coverage and limitations

- German only. Meanings are English glosses from English Wiktionary and are labeled "Meanings (English)" in every interface language; Spanish, French and Dutch glosses would need other Wiktionary editions with different licensing checks and formats.
- 21,568 entries for 19,822 words: 17,096 with IPA, 20,773 with audio, 3,714 with conjugation tables, 12,182 with declension tables, 3,751 with at least one example. 36,972 inflected forms point to their lemma.
- Words outside the static set show "Not in the dictionary yet" and a link to Wiktionary. There is no live Wiktionary API fallback: the Wikimedia REST API expects a descriptive User-Agent and rate-limits unauthenticated clients (see the [Wikimedia API usage guidelines](https://www.mediawiki.org/wiki/API:Etiquette)), it would send every looked-up word to a third party, and a static set keeps the app free, offline-friendly and private.
- Wiktionary is community-edited; glosses can be terse or technical, and some entries lack examples or tables.

## Rebuild

```sh
node --experimental-strip-types scripts/build-lexicon.mjs kaikki.org-dictionary-German.jsonl.gz de_50k.txt 20000
```
